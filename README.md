# SwitchDesk

Управление мышью, клавиатурой и текстовым буфером обмена другого компьютера в локальной сети
или через Tailscale. Как RDP, только экран удалённого компьютера не показывается: монитор стоит
рядом, поэтому нужен только ввод. К одному компьютеру могут подключаться несколько человек
одновременно.

Только Windows. Одно приложение: каждый компьютер может и **принимать** подключения (вкладка
«Этот ПК»), и **передавать** свой ввод на выбранное устройство (вкладка «Устройства»).

## Установка

Скачайте `switchdesk-setup.exe` со страницы [Releases](https://github.com/m-dan12/switchdesk/releases/latest)
и запустите. Установка идёт в профиль пользователя, без UAC. SmartScreen и антивирус могут
предупредить: у установщика нет подписи Authenticode, а программа перехватывает ввод и поэтому
похожа на кейлоггер. Хэши файлов лежат в `SHA256SUMS.txt` в релизе.

## Использование

1. На компьютере, которым будете управлять: вкладка **«Этот ПК»** → включите «Принимать
   подключения». Там же видны адреса (LAN и Tailscale) и токен. При первом запуске Windows
   спросит про доступ в брандмауэре, разрешите.
2. На своём компьютере: **«Устройства»** → «Добавить устройство», введите адрес и токен →
   «Подключиться».
3. **Ctrl+Alt+F12** (из любого окна) или кнопка «Управлять этим компьютером» передаёт мышь и
   клавиатуру на удалённый компьютер, повторное нажатие возвращает их обратно.

Текстовый буфер обмена синхронизируется в обе стороны, в том числе между самими клиентами
через хост. Если окно закрыть, программа остаётся в трее (отключается в «Настройках»).
Тема: тёмная, светлая или системная. Автозапуск при входе в Windows включается в «Настройках».

## Безопасность

- Общий токен, весь трафик шифруется AES-256-GCM (ключ выводится из токена PBKDF2 и случайных
  nonce обеих сторон, счётчик кадров защищает от повторов). Неверный токен = соединение
  закрывается на первом же кадре.
- Токен случайный (24 символа), его нельзя перебирать быстро, но не используйте короткие
  ручные токены.
- «Разрешить управление» на хосте мгновенно замораживает ввод и отпускает зажатые клавиши.
- Окна «от администратора», экран блокировки, UAC и Ctrl+Alt+Del не принимают внедрённый ввод:
  для них хост нужно запускать от администратора.

## Обновления

Приложение проверяет GitHub Releases при запуске и раз в сутки. Если есть новая версия, вверху
окна появляется баннер с кнопкой «Обновить и перезапустить». Установщик подписан ed25519, подпись
покрывает версию и файл, публичный ключ зашит в программу (`update/src/lib.rs`), адреса загрузки
принимаются только с `github.com/m-dan12/switchdesk/releases/download/<тег>/`.

## Выпуск версии

1. Поднять `version` в `[workspace.package]` корневого `Cargo.toml`, закоммитить в `main`.
2. `git tag vX.Y.Z && git push origin vX.Y.Z` (или Actions → Release → Run workflow). Workflow
   соберёт установщик, подпишет и опубликует релиз.

Нужен секрет репозитория `UPDATE_SIGNING_KEY` (пара ключей создаётся командой
`cargo run -p switchdesk-sign -- keygen`, публичная часть идёт в `PUBLIC_KEY_HEX`).

## Состав

| Каталог      | Что делает |
|--------------|------------|
| `app`        | Приложение: окно (egui), трей, хост, клиент, захват ввода, буфер обмена. |
| `update`     | Проверка, загрузка (WinHTTP) и установка обновлений, проверка подписи. |
| `tools/sign` | Утилита релизов: ключи и подпись установщика (не входит в поставку). |
| `installer`  | Сценарий Inno Setup. |

Модули `app/src`: `proto` (протокол и шифрование), `host` (приём ввода), `client`
(подключение), `capture` (хуки и Raw Input), `inject` (SendInput), `clip` (форматы буфера
обмена: добавить картинки или файлы можно отдельным `ClipFormat`), `updater` (фоновое
обновление), `winapp` (трей-окно, один экземпляр, автозапуск), `app` (интерфейс и темы).

## Сборка

```
cargo build --release
cargo test --workspace
```

Иконка пересоздаётся командой `python tools/make_icon.py`.

## Известные ограничения

- Курсор подчиняется настройкам ускорения хоста; на каналах с большой задержкой (больше
  100 мс, например через VPN) мышь подлагивает: проверьте путь Tailscale (`tailscale ping`).
- В буфере обмена пока только текст (до 8 МБ).
- Раскладка и её переключение определяются хостом: клавиши идут по сканкодам.

## Переключение из стороннего меню

Соединения с использованными устройствами остаются открытыми (раз в 5 с идёт проверка связи), поэтому
переключение на уже подключённое устройство мгновенное. Ввод и буфер обмена идут только на активное.

`switchdesk.exe --switch <имя устройства>` подключается к устройству из списка и передаёт на него
ввод, `--switch local` возвращает ввод себе. Если компьютером в этот момент кто-то управляет, команда
уходит управляющему, и он сам решает: выбор самого управляющего просто отключает его от этого
компьютера (циклов не бывает).

## Один управляющий и права администратора

- Хостом управляет один компьютер: когда подключается другой, прежний автоматически отпускает ввод
  (в окне появится «Управление перехвачено другим компьютером»), соединение остаётся в запасе.
- Диспетчер задач и игры с повышенными правами не принимают ввод от обычного процесса. Включите
  «Запускать от имени администратора» в настройках: один запрос UAC создаёт задачу планировщика с
  наивысшими правами, дальше программа стартует с ней без запросов. Экран UAC и Ctrl+Alt+Del
  (защищённый рабочий стол) всё равно недоступны.
- Запуск после обновления и из установщика идёт сразу в трей (`--minimized`).
